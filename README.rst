Discourse Auth for Pretix
=========================

This repository contains the ``pretix-discourse-auth`` Pretix plugin, a
Discourse authentication backend for Pretix. The plugin is distributed as a
standalone Python package and is installed on the Pretix host:

.. code-block:: console

   pip install pretix-discourse-auth

For the current access policy, configuration, workflows, and deployment
requirements, see the `canonical technical specification`_. The specification
is maintained with the Ansible Meetup documentation so that the plugin and
operational guidance have one source of truth.

.. _canonical technical specification: https://docs.ansible.com/projects/meetup/en/latest/reference/pretix-discourse-auth-specification.html

Source code and issue tracking are available in the
`GitHub repository <https://github.com/ansible-community/meetup-pretix-discourse-auth>`_.
