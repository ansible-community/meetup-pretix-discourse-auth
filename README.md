# Discourse Auth for Pretix

This repository contains the standalone `pretix-discourse-auth` plugin package.
Install it on the Pretix host with `pip install pretix-discourse-auth`.

See the [canonical technical specification](https://docs.ansible.com/projects/meetup/en/latest/reference/pretix-discourse-auth-specification.html)
for current access policy, configuration, workflows, and deployment
requirements. The package source and issue tracker are maintained in this
repository.
